# Agenxo

Site de l'agence Shopify Agenxo — création, refonte et migration de boutiques Shopify et Shopify Plus.

## Développement

```bash
npm install
npm run dev
```

Le site est accessible sur http://localhost:3000.

## Contenu

Tous les textes, projets, avis et images se trouvent dans `lib/content.ts`, `lib/catalog.ts` et `lib/blog.ts`.

## Production

```bash
npm run build
npm run start
```
